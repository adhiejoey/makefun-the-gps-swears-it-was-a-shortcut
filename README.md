One line, in the GPS's own voice, excusing the wrong road: the map promised a
bridge, the GPS believed it, the driver believed the GPS, and now everyone is
in the lake together — while the ducks, at least, are having a wonderful day.

## How it works

`main.ts` writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`), using only the Node 22 standard library, no network.
